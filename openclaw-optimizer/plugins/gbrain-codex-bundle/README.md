# gbrain-codex-bundle

Local OpenClaw-compatible Codex bundle that exposes:
- Official gbrain skills (copied from upstream repo)
- A bundled MCP server definition (`gbrain_bundle -> gbrain serve`)

Install:

```bash
openclaw plugins install /home/ubuntu/.openclaw/workspace/openclaw-optimizer/plugins/gbrain-codex-bundle --force
openclaw gateway restart
```
